## Quy tắc cập nhật ma trận

Người cập nhật phải mở file hướng dẫn của module và kiểm đủ điều kiện chuyển nhóm. Mỗi thay đổi cần dẫn artifact cụ thể, gồm source path, test command, result và blocker đã đóng. Không thay đổi phân loại chỉ vì một file mới xuất hiện hoặc compile không lỗi.
