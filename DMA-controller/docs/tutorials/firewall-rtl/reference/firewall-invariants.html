10 invariant tích hợp Firewall

Cheat sheet này diễn giải ngắn; contract V2.4.1 vẫn là SSOT.

  1. Không AW/AR ra matrix trước allow decision.
  2. Không W ra matrix trước allowed AW và downstream AW handshake.
  3. Mỗi channel tối đa một outstanding transaction.
  4. Decision/ID/LEN/mode bất biến sau address acceptance.
  5. Same-cycle priority: done > context allocation > APB write > existing state.
  6. Denied write trả B sau đúng AWLEN+1 W handshakes.
  7. Denied read phát đúng ARLEN+1 R handshakes.
  8. Mọi VALID payload ổn định khi bị stall.
  9. FW_EN=0 không tắt profile/overflow/4 KiB/framing/logging.
  10. Lock/config/fault semantics đúng register map; hardware set thắng W1C.
