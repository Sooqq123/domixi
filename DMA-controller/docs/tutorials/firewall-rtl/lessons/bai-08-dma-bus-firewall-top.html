Bài 08 — dma_bus_firewall

Mục tiêu: tích hợp bảy module thành một Firewall có transaction ownership rõ, reset fail-secure và one-outstanding trên mỗi channel.

Đọc bắt buộc

  • pinout.csv toàn bộ Firewall boundary.
  • detailed_block_diagram.md.
  • firewall_rtl_integration_contract.md toàn bộ invariant.
  • fsm_specification.md priority/ownership/recovery.

Hai ownership slot độc lập

WRITE_OWNER: NONE | ALLOWED | DENIED
READ_OWNER : NONE | ALLOWED | DENIED

Mỗi slot chốt direction, decision, ID, LEN, ERR_MODE và fault metadata. Slot chỉ về NONE tại terminal B hoặc final R handshake. Vì baseline one-outstanding/channel, AWREADY/ARREADY phải phản ánh cả Stage 1 capacity và owner availability.

Atomic decision

Tại address acceptance, effective policy đã áp dụng priority:

done revoke > context allocation > APB write > existing ACL

Descriptor và decision phải chốt nguyên tử. Config/context thay đổi sau đó chỉ ảnh hưởng transaction mới.

Fail-secure reset

rst_n asynchronous assert/synchronous deassert. AXI READY/VALID do Firewall phát giữ 0 đến cạnh release đồng bộ. APB PREADY theo contract bằng 1. Reset phải xóa owner, region active, fault/IRQ/count và đặt FW_EN/AUTO_CTX_EN/ERR_MODE đúng reset value.

Lab integration

  1. Đóng port list bằng pinout; không tự thêm/bỏ sideband.
  2. Instantiate address slice, context tracker, APB regs, matcher, drain và mux.
  3. Nối AW path trước, test allow/deny LEN=0.
  4. Nối W/B và write owner đến terminal.
  5. Nối AR/R và read owner.
  6. Thêm same-cycle context/APB/address tests.
  7. Thêm simultaneous read/write fault logger test.
  8. Randomize matrix backpressure; watchdog phải chứng minh không deadlock.
