APB access hợp lệ

setup  = PSEL && !PENABLE
access = PSEL &&  PENABLE
write_accept = access && PWRITE && PREADY
             && secure_privileged && address_valid

Profile full-word không expose PSTRB. PREADY=1 theo contract. Chỉ PPROT[1]=0 && PPROT[0]=1 được truy cập; forbidden/invalid access phải tạo PSLVERR theo SSOT.

Register semantics phải tách riêng

  • FW_CONTROL @ 0x000: reset 0x0000000D.
  • FW_LOCK @ 0x004: RW1S; set rồi không software-clear được.
  • FAULT_STATUS @ 0x008: W1C với IRQ pending sticky.
  • FAULT_ADDR/INFO/TIMESTAMP/SOURCE: metadata theo event priority.
  • Region 0–7 từ 0x020, stride 0x10; Region 4/5 là dynamic read-only.

Không copy reset/access behavior từ trí nhớ; lấy nguyên giá trị từng field từ register_map.csv.

Concurrent set/clear

Hardware fault set phải thắng software W1C trong cùng cạnh. Metadata event priority và fault count phải đúng SSOT. Dùng next-state combinational hoặc thứ tự nonblocking được thiết kế rõ; không dựa vào “dòng code phía dưới thắng” một cách vô thức.

  4. Test RW1S lock, write sau lock và active-region write protection.
  5. Test W1C riêng lẻ và simultaneous hardware-set/W1C.
  6. Test fault readback, event priority, count và IRQ sticky.
  7. Loop qua toàn bộ region/offset thay vì chỉ region 0.

Exit gate

  • tb_fw_apb_regs PASS toàn map và negative access.
  • Reset, lock, W1C, RO/dynamic region và IRQ đều có checker.
  • Không có writable reserved bit.
  • Người học giải thích được RW1S khác W1C thế nào.
