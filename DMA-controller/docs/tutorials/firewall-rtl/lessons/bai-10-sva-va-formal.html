Bài 10 — Assertions và formal security properties

Mục tiêu: chuyển invariant thành property kiểm tra được, phân biệt assumption/assertion/cover và báo đúng trạng thái khi thiếu formal tool.

Đọc bắt buộc

  • verification_test_plan.md: mọi property ID.
  • firewall_rtl_integration_contract.md: 10 invariant.
  • requirements_traceability.csv: requirement–assertion mapping.

Ba loại property

  • assume: giới hạn môi trường theo hợp đồng hợp lệ; không dùng để giả định chính điều cần chứng minh.
  • assert: behavior DUT bắt buộc.
  • cover: chứng minh scenario có thể đạt tới và chống vacuous proof.

Mẫu property cốt lõi

property p_aw_stable;
  @(posedge clk) disable iff (!rst_n)
  m_axi_awvalid && !m_axi_awready
    |=> m_axi_awvalid && $stable({m_axi_awid,m_axi_awaddr,
                                  m_axi_awlen,m_axi_awsize,
                                  m_axi_awburst,m_axi_awprot});
endproperty

property p_denied_address_isolated;
  @(posedge clk) disable iff (!rst_n)
  (acl_w_fault || acl_r_fault)
    |-> !(m_axi_awvalid || m_axi_arvalid);
endproperty

Tránh proof rỗng

Nếu assumption làm AWVALID luôn 0 thì stability property “PASS” vô nghĩa. Thêm cover cho address acceptance, denied LEN 0/15, stalls và terminal response. Review reachable states và bound đủ dài cho 16-beat drain.

Lab

  1. Bind stable-under-stall assertions cho AW/AR/B/R.
  2. Viết denied address/data isolation.
  3. Viết exact write/read beat và no-early-B.
  4. Viết ID stability, sticky lock, same-cycle revoke.
  5. Chạy assertions trong simulation trước.
  6. Nếu formal engine có, chạy bounded proof với cover; lưu report.
  7. Nếu không có tool, giữ source property và ghi G4 BLOCKED_TOOLING.

Exit gate

  • Mọi property ID có source và requirement mapping.
  • Simulation assertion regression PASS.
  • Formal report PASS hoặc trạng thái BLOCKED_TOOLING chính xác.
  • Assumption/vacuity review được ghi lại.

Câu hỏi kiểm tra

  1. Directed test PASS có thay formal proof được không?
  2. Vì sao cần cover bên cạnh assert?
  3. Bound tối thiểu phải xét behavior 16-beat nào?
